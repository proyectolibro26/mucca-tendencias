# MUCCA — demo web showroom

Demo de web para Mucca Tendencias (showroom de ropa de mujer, España 991 piso 1, Rosario). HTML estático, desplegado en Vercel.

- Prendas, precios y talles: `PRODUCTOS` dentro de `index.html`. Look de la semana: `LOOK`. Categorías: `CATS`.
- Fotos: carpeta `fotos/` (mapeadas en `FOTOS`).
- Número de WhatsApp que recibe pedidos y reservas: `WA`.
- Horarios para reservar visita: función `horasDe`.
- Al final de la página está la propuesta de Roman Web.
