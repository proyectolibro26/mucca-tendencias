# MUCCA — demo tienda online

Propuesta de tienda con carrito y pedidos por WhatsApp (HTML estático). Desplegado en Vercel.

- Catálogo, precios, colores y talles: objeto `P` dentro de `index.html`.
- Looks: `LOOKS`. Destacados del inicio: `HERO`. Formas de pago y descuentos: `PAGOS`.
- Número de WhatsApp que recibe los pedidos: `WHATSAPP`.
